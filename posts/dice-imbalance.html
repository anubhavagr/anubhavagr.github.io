99.6% accuracy, completely useless.

A coronary artery is a thin, bright curve threaded through a dark frame — about 0.4% of the pixels. Train a segmenter on raw cross-entropy and the loss function will quietly agree with a model that predicts nothing. The derivation of why, the geometry of the Dice loss that doesn't, and why thin structures punish every pixel of boundary error.

TaskCoronary segmentation
ArchitectureU-Net · ResNet34
In production0.94 Dice · QCA < 4 s

TL;DR

Cross-entropy's gradient budget is proportional to class frequency — at 1:255 imbalance, 99.6% of the signal says "background," and the loss's global optimum along the model's bias direction is to predict the prior. The soft-Dice loss is normalized by construction and provably pushes the other way. Neither is enough alone — Dice + BCE is the working recipe, and for thin vessels, boundary error is the whole game: a 1-px error on a 2-px vessel costs 33 points of Dice.

Set the stage with arithmetic

Take a 512 × 512 fluoroscopy frame. A coronary artery crossing it might be 2 px wide for most of its length. Foreground pixels: 2 × 512 = 1,024. Total pixels: 262,144. Foreground fraction π = 0.39%. A model that outputs solid black — no vessels, ever — scores 99.61% pixel accuracy. That number should be banned from medical segmentation reports, and its banality is the entry point to the real math.

Derivation 1: where cross-entropy's gradient goes

Per-pixel binary cross-entropy with logits z, softmax probability p = σ(z):

LCE = −[y log p + (1−y) log(1−p)],    ∂L/∂z = p − y

The gradient magnitude for a pixel of class y is |p − y| — the same functional form for foreground and background. But count the pixels: for every foreground pixel there are (1−π)/π ≈ 255 background pixels contributing gradients of the same shape. The aggregate gradient — the thing your optimizer actually descends — splits by class frequency:

background share of gradient = 1 − π = 99.61%

Under trivially wrong predictions, 99.6% of the update signal instructs the network to get better at background. The vessel learns last, from the smallest slice of the gradient, and thin structures are exactly the ones that can't survive a slow start.

The left panel makes a sharper point than "CE is imbalanced." Sweep a model that outputs the same probability q on every pixel — the direction an under-trained, class-starved network collapses along. CE(q) = −[π log q + (1−π) log(1−q)] is minimized at q* = π: the loss's ideal student reproduces the class prior and calls it a day. The soft-Dice loss — derived below — is minimized at q* = 1: every pixel foreground. Each objective has a degenerate optimum, and they point in opposite directions. That symmetry is why the standard fix is to use both.

Derivation 2: the Dice loss, and why it self-normalizes

The Dice coefficient measures overlap: 2|A ∩ B| / (|A| + |B|). Make it differentiable by substituting soft predictions pi ∈ [0,1] against ground truth gi ∈ {0,1}, summed over all N pixels:

D = 2 Σᵢ pᵢgᵢ / (Σᵢ pᵢ + Σᵢ gᵢ)

Differentiate (quotient rule, writing P = Σp, G = Σg, I = Σpg):

∂D/∂pi = 2 [ gi(P + G) − I ] / (P + G)²

Now the key property, visible in that denominator: the gradient is divided by the total mask size (P + G). Whether the foreground is 40% of the image or 0.4%, the gradient scale is normalized — Dice pays each class the same budget, exactly what CE refuses to do. This is why an imbalanced segmentation loss at Dice 0.94 means something: the metric literally cannot be inflated by background.

Dice alone has failure modes too: when the prediction is empty early in training, I → 0 and the gradient gets noisy and sparse (this is the classic cold-start of pure-Dice training); and Dice is an overlap measure, so it says nothing about calibration. The working recipe in ArterySeg and in the production QCA stack is L = Dice + BCE — BCE supplies dense, stable early gradients; Dice supplies the frequency normalization — and each cancels the other's degenerate optimum from the figure above.

Thin structures pay full price for boundaries

Here's the geometry that makes vessel segmentation specifically hard. Say the prediction is perfect except the boundary sits δ px too wide on each side. For a vessel of width w: the intersection keeps w·H, the prediction covers (w + 2δ)·H, and:

Dice = 2w / (2w + 2δ) = w / (w + δ)

One closed-form line, and it convicts: at w = 2, a δ = 1 px error gives Dice = 2/3. A third of the score, gone to a single pixel — and this is sub-visual: 1 px at typical fluoroscopy display scale is inside the annotation noise of the ground truth itself.

This is the argument for architecture that spends capacity on boundaries. ArterySeg runs a custom Sobel edge-enhancement input stage and a spatial-attention block precisely because the loss can only reward sharp boundaries if the network can see them: gradient magnitude at vessel edges is what the attention gates amplify, and the Sobel channel makes edge evidence explicit rather than hoping the encoder learns it. The production descendant of this line — U-Net++ over a ResNet encoder with attention — reaches 0.94 Dice and feeds the automatic QCA measurements cardiologists use in live procedures.

The checklist I actually use

  1. Report Dice (and IoU), never pixel accuracy. If a reviewer asks for accuracy, show them the solid-black model's 99.61%.
  2. Start from Dice + BCE, 1:1. The two degenerate optima cancel; dense early gradients come free from the BCE term.
  3. Sanity-check with the w/(w+δ) formula. Know your structure's width and what 1 px of boundary error costs before blaming the model.
  4. Spend architecture on boundaries — edge priors, attention at skip connections — because for thin structures, the boundary is the object.
