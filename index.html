03How I got here

Griphic — Delhi, India

Jan 2026 — Present
AI Engineer — 2

The brief was an AI interviewer that doesn't feel like a chatbot. The hard part wasn't asking questions — it was actually listening: scoring answers, scaling question difficulty live, and asking the kind of follow-up a real interviewer would. I built the brain behind it.

  • A stateful LangGraph agent — every node a reasoned step, with state carried across turns so the conversation stays coherent over long sessions.
  • A RAG pipeline pulling from three retrieval paths in parallel (conversation embeddings, MongoDB, knowledge vault) with hybrid keyword + dense search and a cross-encoder re-ranker — 0.95 Recall@5 over 10K+ docs.
  • Query latency cut from 2.5s → 0.8s (−68%) by running the paths concurrently and re-ranking only the fused top-K; domain-query F1 +42%.
  • An eval harness (recall, faithfulness, answer-relevance) plus LLM guardrails with citations — so every claim is traceable to a source.

Today: 500+ concurrent users at 99.9% uptime.

Machine Learning Engineer & Team Lead
